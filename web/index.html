Use this phone as your PC's microphone

Safari only allows the microphone on a secure connection. Set it up once:

  1. On the PC, install VB‑Audio Virtual Cable (free, vb-audio.com/Cable) and restart Desk Deck.
  2. Tap Get certificate below, then Allow.
  3. Settings → General → VPN & Device Management → Desk Deck → Install.
  4. Settings → General → About → Certificate Trust Settings → turn on Desk Deck.
  5. Tap Open secure Desk Deck, then Share → Add to Home Screen. Use that icon from now on.

In Discord, Zoom, OBS etc., choose CABLE Output as the microphone.

Use this phone as a second screen

Desk Deck starts spacedesk on the PC for you. Set it up once:

  1. On the PC, install the spacedesk Windows driver (free, spacedesk.net) and restart Desk Deck.
  2. On the iPhone, install the spacedesk app from the App Store.
  3. Tap Second screen here, then open the spacedesk app and tap your PC.

While the phone is a screen it can't show Desk Deck; switch back to the Desk Deck icon when you're done. In Windows display settings you can choose whether it extends or mirrors.
